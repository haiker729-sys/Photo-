Core Platform Modules

Deep Dive Into Studio Modules

Detailed look at the five core operational modules inside Jummo Photos AI.

MODULE 01

Photographer Dashboard & Admin Suite

The Home Dashboard displays a live 3+2 telemetry grid (Events, Photos, Uploaded, Pending, Failed), side-by-side + Create Event and Camera buttons, Google Drive sync status, and Recent Events. The Admin Dashboard adds role-based governance across 14 studio management modules.

MODULE 02

Event QR Sharing

Powered by QrCodeGenerator.kt, every event receives a deterministic QR matrix and a branded studio QR card displaying the event name, category, and date. Photographers can set QR expiration dates, pause/resume access, save the QR card to the device, or share it via Android’s Share sheet.

MODULE 03

Google Drive Integration

In Profile & Settings → Google Drive, photographers configure their target cloud folder (default: Jummo_Events_Cloud) and monitor connection state. The architecture is designed for server-side OAuth token exchange so sensitive client secrets are never hardcoded in the APK.

MODULE 04

Consent-First AI Face Search

In GuestPortalModalScreen.kt, the face-search action remains locked until the guest explicitly checks the biometric consent box. Consent sessions are recorded in Firestore scoped strictly to that single eventId, with 1-tap session purge and mismatch reporting.

MODULE 05

Guest Photo Gallery

Features a responsive 3-column thumbnail grid with All Photos, People (AI), and Highlights filter tabs, multi-select batch toolbar (Select, Download, Share, More), and per-event download authorization enforcement.

MODULE 06

Local Original Protection

Every captured frame and imported DSLR photograph is written to filesDir/photos/<eventId>/ and tracked by PhotoUploadWorker. Background workers never delete local originals after upload completion.

PRIVACY POLICY

Consent-First Data Privacy

1. Explicit guest consent is required before any AI Face Search session is registered.
2. All event records, uploads, and guest sessions are isolated by userId and eventId in Cloud Firestore.
3. Guests and studio owners can permanently delete face-search sessions at any time.

TERMS OF SERVICE

Studio Ownership & Usage Terms

1. Photographers retain 100% ownership over all captured and imported event photographs.
2. Event QR codes obey photographer-configured expiration dates and access modes.
3. Local original files in filesDir/photos remain under the photographer’s control.
